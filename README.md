# 스텝캡처 — 설치 파일

클릭할 때마다 화면 한 장과 설명 한 줄을 남기는 튜토리얼 제작기 **스텝캡처**의 설치 파일을 올리는 곳입니다.
코드는 따로 둡니다 — 여기에는 [릴리스](../../releases)만 있습니다.

- **설치:** 맨 위 릴리스의 `StepCapture-Setup-<판>.exe` 를 받아 더블클릭 — 이 사용자에게만 깔리고 관리자 권한이 필요 없습니다 (윈도우 10 2004 이상).
- 서명하지 않은 파일이라 처음에 'Windows의 PC 보호'가 뜰 수 있습니다 → '추가 정보 → 실행'.
- **업데이트:** 이미 깔려 있으면 스텝캡처를 켤 때 새 판을 확인해 시작 화면에 '새 판이 있습니다 → 지금 업데이트'를 띄웁니다.
  인터넷이 GitHub 내려받기를 막는 곳(일부 학교망)에서는 확인이 안 될 수 있습니다 — 그때는 여기서 받아 다시 까세요.
